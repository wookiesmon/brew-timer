# Drip Coffee Timer ☕

A bilingual (English/한국어) pour-over brew timer for iPhone and any phone browser.

**Use it:** https://wookiesmon.github.io/brew-timer/

- 16 bean profiles across popular origins (Ethiopia, Kenya, Colombia, Brazil, Honduras, Guatemala, Costa Rica, Indonesia — Sumatra, Sulawesi, Java, Bali — Gesha, anaerobic, blends + custom)
- 5 brew methods: Bean-tuned, 4:6 (Tetsu Kasuya), Hoffmann, 점드립 (Korean jeom-drip), and Momos Coffee's official store recipe
- HOT and ICED modes, phase-by-phase pour targets, audio chimes, screen wake-lock
- Add to Home Screen for an app-like experience
